Troubleshooting common integration issues
The table is unstyled
Import the matching stylesheet globally. Complete uses styles.css; Base uses base.css; Lite uses lite.css.
Selection disappears after changing data
Set getRowId to a stable, unique record ID. Avoid array positions as IDs for sortable or changing data.
The table resets on every render
Keep the options object reference stable. In React, create it outside the component or with useMemo.
A detail row repeats the parent data
Use renderDetailPanel for custom details. Real child rows require getSubRows or loadSubRows.
